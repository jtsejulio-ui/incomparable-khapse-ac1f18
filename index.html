ACOMPANHAMENTO PEDAGÓGICO

Grupos de apoio inteligentes

Grupos equilibrados por turma: as médias dos grupos ficam o mais próximas possível. Os grupos somam pontos pela evolução semanal e, às segundas-feiras, grupos com mais de 7 pontos geram uma nota para todos os elementos.

Os grupos são uma proposta automática: reveja e ajuste a composição antes de os aplicar.

Pontos de acompanhamento dos grupos

Os pontos positivos/negativos são independentes das notas oficiais. O sistema também pode lançar pontos automaticamente a partir da evolução da média coletiva mensal (a partir de novembro de 2026); os lançamentos manuais continuam disponíveis para colaboração, participação e tarefas.

Bónus semanais (segundas-feiras)

Todas as segundas-feiras o sistema calcula a variação semanal da média de cada grupo e atribui pontos. Se um grupo tiver mais de 7 pontos disponíveis, cada elemento recebe uma nota igual aos pontos (máximo 10) e os pontos usados são descontados.

Configurações e segurança

👥 Perfil e colaboração entre professores

Cada professor mantém o seu perfil e os seus dados neste telemóvel. A colaboração é organizada por turma: só os dados da turma escolhida entram no ficheiro partilhado.

📲 Link para descarregar a aplicação

Publique esta versão num serviço de alojamento (por exemplo, Netlify) e coloque aqui o endereço público. Depois, toque em «Enviar pelo WhatsApp»: a pessoa recebe o link, abre-o no telemóvel e pode instalar a aplicação. O link só funciona depois de a versão estar publicada na Internet.

O link só ficará disponível para outras pessoas depois de publicar o ficheiro actualizado na Internet.

🔗 Espaço comum de uma turma

Escolha uma turma para preparar um pacote de colaboração. Envie o ficheiro aos colegas que lecionam nessa mesma turma. A importação combina os registos sem substituir o que já existe.

Os dados não são enviados automaticamente para a Internet.

Regra de segurança: Turma A, Turma B e Turma C têm pacotes separados. Partilhe cada pacote apenas com os professores dessa turma. Antes de juntar ficheiros, confirme o nome da turma.

☁️ Sincronização online por turma (V72)

Crie uma sala digital para cada turma e convide apenas os professores autorizados. Depois de entrar na sala, as alterações são enviadas automaticamente e os outros dispositivos recebem actualizações em cerca de 15 segundos. A aplicação continua a guardar localmente quando está sem Internet. É necessário executar o ficheiro SQL V72 no Supabase.

A sincronização automática começa depois de configurar o Supabase e criar ou entrar na sala da turma. A colaboração por ficheiro continua disponível.

Privacidade: o código de convite funciona como uma chave de acesso à sala. Partilhe-o apenas com os professores autorizados. Não coloque dados de outras turmas nessa sala. O projeto Supabase e a política de acesso devem ser configurados pelo administrador.
